# Riccati identity

Original PNG images supplied by the project owner in chat on 2026-10-21. Company reference: https://www.riccati.cr/

The source images are kept unmodified. RiccatiLogo uses a CSS viewport to frame the wordmark/full lockup without the large surrounding canvas. The original white-on-black artwork uses screen blending on dark surfaces and inversion with multiply blending on light surfaces. These presentation rules apply only to these monochrome assets.
